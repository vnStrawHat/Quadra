# Release notes

Markdown opens a `.md` file to **read** it, and edits it: *Raw*, *Side by side* or *Preview*.

## What is new

- The panes scroll together by their headings.
- A heading chosen on one side is shown on the other.
- [ ] A task not done yet
- [x] A task done

> A quote: the toolbar formats and inserts.
